# Van Şehir Rehberi

Van şehir tanıtım sitesi - 11. sınıf HTML, CSS, Bootstrap, jQuery proje ödevi.

## Özellikler

- **Ana Sayfa** - Karşılama mesajı, günün Van bilgisi, öne çıkan kartlar
- **Tarihçe** - Van'ın tarihi hakkında bilgiler
- **Gezilecek Yerler** - Van Kalesi, Akdamar Adası, Hoşap Kalesi ve daha fazlası
- **Yemekler** - Otlu peynir, murtuğa, keledoş ve diğer Van lezzetleri
- **Müzeler** - Van Müzesi ve diğer müzeler
- **Galeri** - Filtreleme özellikli görsel galeri
- **İletişim** - İletişim formu
- **Detay Sayfaları** - Her mekan/yemek için özel sayfalar
- **Sürpriz** - "van" yazınca gizli içerik

## Kullanılan Teknolojiler

- HTML5
- CSS3 (Bootstrap 5.3)
- JavaScript (jQuery 3.6)

## Kurulum

Projeyi klonlayın ve `index.html` dosyasını tarayıcıda açın.

```bash
git clone https://github.com/ahmetokan0101/van-rehberi.git
cd van-rehberi
```

Herhangi bir sunucu gerektirmez, doğrudan çalıştırabilirsiniz.
